# DESIGN.md — Playful Consumer

## Personality
Friendly, upbeat, approachable. Color and rounded shapes carry the mood.

## Colors
- Background: #FFF8F0 (cream); surfaces #FFFFFF
- Text: #1F1D2B (primary), #5B5870 (secondary)
- Palette (use 1 primary per screen, others as accents): coral #FF6B6B, sunshine #FFD93D, mint #6BCB77, sky #4D96FF, lilac #B388FF
- Tints at 15% for backgrounds behind icons/badges

## Typography
- Headings: Poppins 700, 44/32/24, slightly rounded feel
- Body/UI: Nunito 17px/1.6; buttons Nunito 700
- Friendly copy; sentence case; short lines

## Layout & spacing
- 8px grid; max width 1100px; sections 88px / 48px mobile
- Radius 24px cards, 999px buttons/chips; thick 2px borders in the primary color allowed
- Illustrations or emoji-scale icons in tinted circles; asymmetric blob shapes as section backgrounds

## Components
- Primary button: coral bg, white text, 48px, radius 999px, shadow 0 6px 0 darker coral (offset "press" look)
- Chips: tinted bg, dark text, radius 999px
- Cards: white, radius 24px, soft shadow 0 10px 30px rgba(31,29,43,0.08)
- Inputs: 48px, radius 16px, 2px border in the primary at 40%
- Empty states: illustration + one-line encouragement + primary action

## Motion
- Springy: 250ms with slight overshoot on buttons; micro-bounces on success; confetti sparingly

## Do / Don't
- Do: one strong primary color per page, rounded shapes everywhere, warm microcopy
- Don't: sharp corners, gray-on-gray, dense tables, more than three palette colors on one screen
